# Design System & UI Specifications

## Color & Theme
* **Theme Default:** Dark Mode First
* **Background Primary:** Dark Slate (`#0F172A`)
* **Background Secondary / Cards:** Deep Charcoal (`#1E293B`)
* **Primary Brand Accent:** Electric Violet (`#6366F1`)
* **Secondary Brand Accent:** Cyan (`#06B6D4`)
* **Text Primary:** Pure White (`#F8FAFC`)
* **Text Secondary:** Slate Muted (`#94A3B8`)
* **Status Colors:**
  * Success / Active: Emerald Green (`#10B981`)
  * Warning / Fallback: Amber (`#F59E0B`)
  * Error / Failure: Rose Red (`#F43F5E`)

## Fonts & Typography
* **Primary UI Font:** `Inter`, system-ui, sans-serif
* **Monospace Font (Code & JSON Payloads):** `JetBrains Mono`, `Fira Code`, monospace
* **Hierarchy:**
  * `H1`: 2.25rem (36px), SemiBold
  * `H2`: 1.5rem (24px), Medium
  * `Body`: 0.875rem (14px), Regular
  * `Code Snippets`: 0.8125rem (13px), Regular
